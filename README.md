# OIBSIP_Datascience_Task5
Sales Prediction Using Python

1. Project Overview

This project uses Machine Learning regression techniques to predict product sales based on advertising expenditure across three media channels: TV, Radio, and Newspaper.

2. Objective

To analyse the relationship between advertising expenditure and sales and develop regression models to predict product sales.

3. Dataset

Dataset: Advertising.csv (Kaggle)

Features:

* TV – TV advertising expenditure
* Radio – Radio advertising expenditure
* Newspaper – Newspaper advertising expenditure
* Sales – Target variable

4. Technologies Used

* Python
* Jupyter Notebook
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn

5. Project Workflow

* Data loading and preprocessing
* Exploratory Data Analysis (EDA)
* Data visualization and correlation analysis
* Train-test splitting
* Regression model development
* Model evaluation and comparison
* Residual analysis and feature importance

6. Machine Learning Models

* Linear Regression
* Polynomial Regression
* Random Forest Regressor

7. Evaluation Metrics

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score

8. Conclusion

The project demonstrates how regression algorithms can predict product sales using advertising expenditure. It also helps identify the advertising channels most strongly associated with sales.
